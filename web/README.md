# 🌐 البوابة السحابية لإدارة المقاهي والتراخيص (Cafe POS Cloud Portal)

بوابة ويب متكاملة مصممة بواجهات زرقاء عصرية وسريعة الاستجابة على الهواتف والكمبيوتر، تدعم نظام **3 أدوار (Roles)** وعزلاً تاماً لبيانات كل رخصة/مقهى (Multi-Tenant Isolation).

---

## 👥 الأدوار الثلاثة في النظام (3 Roles):

### 1. 👑 الأدمن (Super Admin)
- **إدخال وإدارة إيميلات العملاء**: إضافة عميل جديد، تعيين الإيميل، كلمة المرور، اسم المقهى، وربطه برخصته الخاصة.
- **إدارة التراخيص (Licenses)**:
  - توليد مفاتيح التراخيص (`CAFE-XXXX-XXXX`).
  - تحديد الصلاحية (بالأيام أو الأشهر أو سنة كاملة).
  - تفعيل / إيقاف التراخيص فوراً.
  - فك قفل الجهاز (Reset Device Lock) لنقل الرخصة إلى جهاز كمبيوتر جديد.
- **الموافقة على طلبات التراخيص**: استقبال طلبات التجديد من العملاء والموافقة عليها مع تحديد المدة المعتمدة.
- **متابعة طلبات التعديلات**: الرد على طلبات التعديلات البرمجية والدعم الفني المرسلة من العملاء.
- **مراقبة جميع المقاهي**: استعراض مبيعات وأصناف أي مقهى.

### 2. 👔 المدير (Manager)
- **الموافقة على طلبات التراخيص**: مراجعة طلبات التجديد وتحديد المدة الممنوحة للعميل.
- **متابعة التعديلات**: الرد على العملاء وتحديث حالة طلبات الدعم.
- **استعراض التراخيص والمقاهي**: متابعة المبيعات والمخزون.

### 3. ☕ الكاستمير / صاحب المقهى (Customer)
- **بطاقة رخصتي**:
  - عرض مفتاح الترخيص، الأيام المتبقية، وتاريخ الانتهاء.
  - **زر "⚡ طلب ترخيص / تجديد"**: يرسل طلباً للإدارة بالمدة المطلوبة (شهر، 3 أشهر، 6 أشهر، سنة)، وبمجرد موافقة المدير/الأدمن **تتجدد رخصته وتصله المدة فوراً وبشكل تلقائي**.
  - **زر "📝 طلب تعديل معين"**: يرسل طلباً لأي ميزة أو تعديل يحتاجه في مقهاه ويتابع رد الإدارة وحالة التنفيذ.
- **مبيعاتي**: عرض مبيعات الوردية واليوم وإجمالي الطلبات وفواتير مقهاه فقط.
- **أصنافي ومخزوني (عزل تام برقم رخصته)**:
  - إضافة منتجات جديدة وتعديل أسعارها والكميات المتوفرة (Stock) وتنبيهات النواقص.
  - **مضمونة 100% أن الأصناف تُحفظ لرخصته هو فقط (`cafe_branches/{licenseKey}`) ولا يراها أو يتأثر بها أي مقهى آخر!**

## 🔑 الحسابات الافتراضية الجاهزة للتجربة:

| الدور | البريد الإلكتروني | كلمة المرور | الصلاحيات |
|---|---|---|---|
| **الأدمن** | `admin@cafepos.com` | `admin123` | تحكم كامل، إدارة التراخيص والعملاء والموافقات |
| **المدير** | `manager@cafepos.com` | `manager123` | موافقة على التراخيص، متابعة التعديلات والمبيعات |
| **الكاستمير** | عبر مفتاح الترخيص مباشرة أو إيميل العميل | — | مبيعاته، أصنافه الخاصة، وطلب التجديد والتعديل |

> 💡 **ميزة الدخول السريع لأصحاب المقاهي**: يمكن لأي صاحب مقهى الدخول فوراً عبر كتابة **مفتاح الترخيص الخاص به** في صفحة الدخول دون الحاجة لحفظ إيميل أو كلمة مرور!

## 🚀 طريقة التشغيل والرفع:

### محلياً (Localhost مع WampServer أو XAMPP):
1. انسخ مجلد `web/` إلى مجلد السيرفر (مثل `C:\wamp64\www\cafe-portal` أو `C:\xampp\htdocs\cafe-portal`).
2. افتح المتصفح على الرابط:
   `http://localhost/cafe-portal/`

### على استضافة ويب حقيقية (cPanel / Hostinger / أي سيرفر PHP):
1. ارفع محتويات مجلد `web/` إلى الاستضافة داخل `public_html` أو دومين فرعي مثل `pos.yourcafe.com`.
2. تأكد أن إصدار PHP هو 7.4 أو 8.0 أو 8.1 أو 8.2 أو 8.3 أو 8.4.
3. كل الاتصالات مع Firebase مؤمنة وتعمل فوراً عبر REST API بدون الحاجة لتثبيت أي مكتبات خارجية!
